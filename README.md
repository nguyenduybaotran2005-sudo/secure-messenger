# secure-messenger
A modern, browser-based secure messaging interface with crypto-themed UI.

[![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![GitHub Pages](https://img.shields.io/badge/demo-live-brightgreen.svg)](https://<ten-user>.github.io/secure-messenger/)
[![Tech Stack](https://img.shields.io/badge/tech-HTML5%20%7C%20CSS3%20%7C%20CryptoJS-red.svg)](#technologies)

An interactive, end-to-end simulation of encrypted communication featuring a modern cybersecurity terminal interface.

---

## Features
* **Modern Dark/Cyber UI:** Atmospheric background gradients, glowing alerts, and a dedicated process log console.
* **Cryptographic Flow Visualization:** Step-by-step display of encryption keys, hashes, and integrity checks.
* **Interactive Walkthrough:** Integrated onboarding tour using Driver.js.
* **Zero Dependencies Setup:** Pure frontend implementation running completely inside the browser.

---

## Technologies Used
* **Frontend:** HTML5, CSS3 (Modern Flexbox, CSS Variables, Glassmorphism)
* **Fonts & Icons:** FontAwesome 6, Google Fonts (*Quicksand*, *JetBrains Mono*)
* **Libraries:** [CryptoJS](https://cdnjs.cloudflare.com/ajax/libs/crypto-js/4.1.1/crypto-js.min.js), [Driver.js](https://driverjs.com/)
